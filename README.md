# Sayan Mondal | Portfolio

A futuristic personal portfolio for **Sayan Mondal**, Robotics & Automation engineering student at The Neotia University, West Bengal, India.

**Live site:** https://sayanexam9734-create.github.io/sayan-portfolio/

## Features

- Interactive 3D humanoid robot "A1 2100" (Three.js): its head follows your cursor, it waves when tapped, and it stands on a holo-platform next to a live holographic globe panel
- ZONIX boot-up loading screen with progress counter
- Particle network background that reacts to the mouse, neon grid floor, HUD panels, scrolling skills ticker and live clock
- Premium gold-styled About section
- Contact section with phone, email and a floating WhatsApp chat button
- Fully responsive, with reduced-motion support
- Single `index.html` file: no build step (Google Fonts and Three.js load from a CDN)

## Run locally

Open `index.html` in any browser.

## Deploy on GitHub Pages

1. Push all files to the repository root.
2. Go to **Settings → Pages**.
3. Set **Branch** to `main` and folder to `/ (root)`, then save.
4. The site goes live in a minute or two.

## Customize

- Contact details (phone, email, WhatsApp link) are in the Contact section of `index.html`.
- Add new projects by copying a `.project` block inside the Featured Projects section.

## Tech

HTML, CSS, vanilla JavaScript and Three.js (r128). Fonts: Orbitron, Rajdhani, Share Tech Mono.
